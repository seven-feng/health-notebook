# 指标页 · 紧凑列表原型

预览：http://127.0.0.1:4173/?metrics=1

本轮只修改浏览器原型，正式 React Native App 及手机上的指标页未变。

## 阅读顺序

先看每个指标最近一次已核对的结果：示例共 10 项，3 项超出参考范围、6 项范围内、1 项报告未提供范围。顶部三个数量都可点击筛选，再点一次或“查看全部”恢复。默认把超出范围的项目排在前面，其余保持示例报告顺序，不按所谓严重程度排序。

列表展示名称、名称旁的单位、最近数值、检查日期和该次报告的参考范围。数值旁只保留红色向上箭头或蓝色向下箭头，不再显示“偏高/偏低/范围内”文字；展开后的历史结果也采用相同表达。范围内的数值不加状态标记，缺少参考范围仍在参考范围位置说明。屏幕阅读器保留状态说明，顶部统计筛选保留文字。

点一行原地展开，展示较上次变化、真实日期间隔的折线图、各次结果及各次参考范围。一次展开一项；再次点行可收起。范围一致时画浅绿色参考带；历史范围不同时不套用统一参考带，各次范围分别列出。缺少范围时保留趋势且不判断偏高偏低。只有一次结果时显示记录，不伪造趋势。

家庭切换仍作用于整个档案。“我”提供完整样例；“妈妈”有两项；“爸爸”有单次且全部范围内的结果；“孩子”展示尚无可比较指标的空状态。未提供范围与无超出项的筛选均有独立空状态。尿酸最近日期较旧，保留 2026.07.12，避免误认为所有指标来自同一次检查。

## 视觉与数据范围

颜色、字体、圆角和边距依据原生 src/ui.tsx 及真实指标页截图；本次新设计的是概览、紧凑列表、展开和参考范围表达，并非旧页面像素复刻。图表由 Recharts 数据渲染。所有示例范围、数值均为设计演示资料，不读取医疗记录。

这批指标使用独立的固定演示数据，家人原型的导入操作不会自动生成新指标。接入正式 App 时需要从已核对 Observation 获取数值和该次 reference，沿用单位/标本/检测方法的比较边界；本轮没有修改提取、匹配或医学判断规则。

## 已验证

两种手机预设、筛选/恢复、展开/收起、不同历史范围、缺失范围、单次记录、空筛选、家庭切换与空档案均在浏览器检查。构建及运行时完整性校验通过，浏览器错误日志为空。截图及对照位于 qa/metrics/，详见 design-qa.md。
