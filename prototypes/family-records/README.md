# 多成员健康记录交互原型

预览：http://127.0.0.1:4173/

整份报告删除探索：http://127.0.0.1:4173/?delete=1 。底部“删除整份报告”打开范围确认；原件预览可通过“管理报告”返回。仅操作虚构的会话数据，刷新恢复；尚未接入手机 App。

沿用 Doctor App 的记录、指标和设置页面，通过右上角成员按钮切换当前档案。

- 默认打开“我”；切换到妈妈、爸爸或孩子后，报告数量、待核对报告、时间线与指标均只展示该成员的数据。
- 在指标或设置页切换成员，仍留在当前页面。
- 导入到当前成员的档案。正常导入不再重复选择归属；姓名不一致时提醒核对，不会自动分配或切换到其他成员。
- 暂存报告留在当前成员的时间线，已核对报告才参与指标比较。
- 成员切换弹层可添加新成员，新成员从空档案开始。设置保留本地资料、识别范围、使用统计和关于，并提供成员入口。
- 不再使用全家的“待分配报告”入口或专门的家庭首页。

使用内存中的虚构数据；刷新页面会恢复初始资料和默认成员。导入 PDF、拍照和相册均为示例场景入口，未接入 SQLite、OCR、真实文件、系统相机或同步。报告页用五项示例结果演示归属，完整指标编辑、原图核对、就诊记录编辑、报告移动等仍以正式 App 的后续实现为准。

## 开发

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
npm run build
```

界面代码：`src/Prototype.tsx`、`src/prototype.css`。手机外壳与键盘沿用 Product Design 模板，受保护运行时未修改。本轮验证与截图见 `design-qa.md`、`qa/v2/`；`qa/` 根目录保留上一版历史截图，不代表现行方案。
