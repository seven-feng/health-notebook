## 真机安全区域修正

用户反馈 iPhone 13 顶部品牌、跳过与系统时间、电量重叠，底部按钮也缺少手势区域留白。原因是全屏 Modal 的原生视图树独立，内部 SafeAreaView 缺少就近的 SafeAreaProvider；仅有外层 React 上下文不能保证原生留白生效。

已在 Modal 的 GestureHandlerRootView 内增加局部 SafeAreaProvider，引导和图片放大共用；未写死机型高度。新增 header/footer 的 testID 便于布局测量。类型检查、文件 lint、既有 5 项引导测试通过。

真机重新加载后，只读检查确认 Modal 内容已包含局部 SafeAreaProvider；系统当前报告顶部 47pt、底部 34pt。引导当时已由用户关闭，因此这组数值是系统安全区域，不能作为引导内控件位置的测量结果。证据：tmp/onboarding-device/insets-after.json、insets-launch.json。需要从设置 → 使用引导重新打开查看实际效果。
