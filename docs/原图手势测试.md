# 原图手势测试

> **专题历史记录。** 下文结果与安装模式只对应各段记录的时间，不代表当前手机状态或全部功能验收。最新汇总见[当前状态与待办](当前状态与待办.md)，日常运行见[本地开发与测试](本地开发与测试.md)。

测试依赖两端已经安装新调试包、Metro 正常运行，以及已导入并确认的两份合成示例。仅修改合成报告的未保存草稿，不确认真实报告。普通页面流程运行 `.maestro/source-preview.yaml`；Maestro 2.11 不支持 pinch，所以双指操作由系统原生测试单独验证。

默认连接 8081。使用独立测试服务时可先 `npx expo start --dev-client --port 8082 --clear`，并在下方 `npm run e2e:*` 前加 `DOCTOR_METRO_PORT=8082`。修改原生依赖后，已有 Metro 必须重启；Android 切换服务时如仍恢复旧服务，可先在开发启动页选择新服务。

## iOS

以下从项目根目录执行；将设备 UUID 换成 `xcrun simctl list devices booted` 中的目标设备。先准备合成报告原图片段，测试会检查双指放大、拖动、缩小、双击放大与恢复、关闭重开后的缩放复位、返回位置以及草稿 79 保留。

```bash
npm run e2e:ios -- .maestro/source-preview-ready.yaml
GEM_HOME=/opt/homebrew/Cellar/cocoapods/1.16.2_1/libexec /opt/homebrew/opt/ruby/bin/ruby scripts/prepare-ios-gesture-tests.rb
xcodebuild test \
  -project tmp/gesture-tests/SourceGestureTests.xcodeproj \
  -scheme SourceGestureTests \
  -destination 'platform=iOS Simulator,id=69C4BB32-F305-4B7F-B3A0-EBF8914DB39C' \
  -derivedDataPath .local/gesture-tests CODE_SIGN_IDENTITY=-
```

Ruby 路径是本机 CocoaPods 的运行环境；其他电脑使用安装了 `xcodeproj` gem 的 Ruby。结果保存在 `.local/gesture-tests/Logs/Test/`。可添加尚不存在的 `-resultBundlePath test-results/自定义名称.xcresult` 固定结果位置。

## Android

先在 `android/` 构建测试 APK：

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew :local-pdf:assembleDebugAndroidTest -PreactNativeArchitectures=arm64-v8a
```

回到项目根目录准备页面，安装并只运行手势测试：

```bash
npm run e2e:android -- .maestro/source-preview-ready.yaml
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 install -r modules/local-pdf/android/build/outputs/apk/androidTest/debug/local-pdf-debug-androidTest.apk
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am instrument -w \
  -e class expo.modules.localpdf.SourceGestureTest \
  expo.modules.localpdf.test/androidx.test.runner.AndroidJUnitRunner
```

测试用真实的多点触摸事件操作当前页面，断言缩放倍率、图片像素变化、返回位置和草稿保留。截图保存在测试包的 `files/viewer-native-pinch.png`，不进入产品文件目录。

测试后返回记录页会丢弃临时输入，原报告依然为 80。也可运行 `.maestro/source-preview.yaml` 验证退出后的趋势仍为 -20。每台模拟器同一时间只运行一个自动化流程。
