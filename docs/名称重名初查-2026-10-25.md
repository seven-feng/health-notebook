## App Store 证据

使用 Apple 官方 iTunes Search API，参数 `country=cn&entity=software&limit=200`，逐一查询四个名称并检查返回的标题和开发者。结果总数包含相关应用，不等于同名应用数。

- [就医记查询](https://itunes.apple.com/search?term=%E5%B0%B1%E5%8C%BB%E8%AE%B0&country=cn&entity=software&limit=200)：58 条相关结果。近似产品开发者为 **LEAN ASIA CO., LTD**，App ID **6772257243**；[商店链接](https://apps.apple.com/cn/app/id6772257243)。官方 API 返回的标题为「就医记录-看病日记·病历本·复诊提醒·健康档案管理助手」。随后尝试打开商店详情网页时遇到网络变化错误，判断依据为已成功返回的官方 API。
- [医路记查询](https://itunes.apple.com/search?term=%E5%8C%BB%E8%B7%AF%E8%AE%B0&country=cn&entity=software&limit=200)：170 条相关结果。已存在品牌为「医路记」，开发者 **Jiangsu Xinghui Shuzhi Technology Co., Ltd**，App ID **6805002585**；[商店链接](https://apps.apple.com/cn/app/id6805002585)。不能因完整标题含有副标题，就误判为没有重名。
- [健康有数查询](https://itunes.apple.com/search?term=%E5%81%A5%E5%BA%B7%E6%9C%89%E6%95%B0&country=cn&entity=software&limit=200)：64 条相关结果，未见标题含完整候选名称。
- [健康小本查询](https://itunes.apple.com/search?term=%E5%81%A5%E5%BA%B7%E5%B0%8F%E6%9C%AC&country=cn&entity=software&limit=200)：138 条相关结果，未见标题含完整候选名称。

[医路记官网](https://medipath.bitbeam.cn/)已打开核实：品牌为「医路记 MediPath」，运营方为江苏星辉数智科技有限公司；网站介绍家庭就医档案、检验指标变化、PDF 导入、拍照归档，并提供相同 App ID 的苹果下载链接和 Android APK。以上为官网公开介绍，未实际测试其功能、识别效果或收费交付。
