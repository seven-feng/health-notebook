## 2026-10-27：趋势图日期标签重叠修复

低密度脂蛋白-C 有 4 次结果时，旧逻辑只按记录数量选首、中、末日期；真实时间轴上相邻检查可能很近，导致中间日期和末次日期文字重叠。改为 `metric-date-labels.ts` 按图表实际宽度、标签字数和首尾对齐方式预留文字空间，并至少留 10 点间隙。优先显示首尾日期，最多再选一个有足够空间且靠近时间轴中间的日期；跨年保留年份，窄容器进一步减少标签。

只调整横轴文字选择，不移动数据点、不把时间间隔改成等间距；所有检查结果、完整日期和原件入口仍保留在历史列表及读屏描述中。同日多次仍只有一个日期标签。

验证：`npm run verify` 通过，40 套／533 项 Jest、类型检查、lint、统计 HTTP 测试。7 个新增合成用例覆盖首端／末端日期密集、跨年、按时间位置选择中间日期、窄容器、同日及空布局。iPhone 上读取实际渲染位置复现重叠；完整重载后再次展开同一指标，306 点宽图表的 3 个日期标签已分开，4 个结果点保持。未改动手机报告数据。此轮为共用组件测试及 iPhone 运行时验证，没有新增原生截图或 Android 专项验收。
